# Структуры каруселей

## 1. Крючок и разворот (формат по умолчанию)

Используется для: историй, мнений, разборов, тем «почему так вышло».

- Слайд 1 — крючок: короткое, дерзкое утверждение, которое цепляет и
  заставляет листать дальше.
- Слайд 2 — усиление или неожиданный переворот той же мысли; ключевые слова
  можно выделить.
- Средние слайды — раскрытие мысли: «почему так», с конкретикой, один блок
  мысли на слайд.
- Финал — неожиданный вывод или прямой призыв к действию (написать в
  директ, сохранить, поделиться, подписаться).

## 2. Сравнение

Используется для: тем «плохо / хорошо», «было / стало», «миф / факт»,
«слабое / сильное».

- Два варианта одного и того же показаны рядом — слабый и сильный (или
  неправильный / правильный).
- Разница должна считываться с одного взгляда, без долгих объяснений.

## 3. Список-инструкция

Используется для: тем, которые естественно превращаются в перечень шагов,
инструментов, лайфхаков, фактов.

- Заголовок-обещание — что узнает читатель.
- Пронумерованный список: один пункт = одна мысль + короткая подпись.
- Отдельный вывод не обязателен — сам список и есть ценность.
- Если пункты списка — конкретные инструменты, сервисы или продукты, каждый
  пункт называется по имени («Midjourney», «HeyGen»), а не общей категорией
  («приложение для видео», «сервис для текста»). Категория (если нужна) идёт
  вторым словом, после названия.

## Как выбирать формат по теме

- Тема про сравнение чего-либо → «Сравнение».
- Тема — список шагов / инструментов / лайфхаков → «Список-инструкция».
- Всё остальное (истории, мнения, разборы) → «Крючок и разворот» (формат по
  умолчанию).

## Общие правила для любого формата

- Слайдов: 6–10.
- Текст на слайде: максимум 1–2 коротких предложения. Никаких сплошных
  абзацев.
- Тон: экспертно, уверенно, дерзко, познавательно, интересно, вирусно.
- Чего избегаем:
  - канцелярита («данный», «осуществляется», «в рамках»);
  - кликбейта без содержания («10 секретов, о которых вам не расскажут»);
  - обещаний результата, которые нельзя гарантировать («заработаете X за
    неделю»);
  - воды не по теме поста;
  - сложных расчётов и цифр, которые надо считать в уме, — вместо этого
    наглядное сравнение или образ («один хороший диван переживёт три
    дешёвых» вместо таблицы цен за год).

## Формат вывода

Текстовая раскадровка, по блоку на слайд:

`Слайд 1: заголовок · текст · что на картинке`

Дизайн, фото и вёрстка — не задача генератора, финальную сборку карусели
всегда делает автор вручную.
