# Генератор каруселей (carousel-generator)

Скил (skill) — это повторяемая инструкция для Claude: один раз описываешь,
как делать задачу, и потом просто просишь коротко, без объяснений заново.

Этот скил помогает Claude собрать текстовый план карусели (серии слайдов
для Instagram или похожей соцсети) под любую тему и нишу — сам выбирает
подходящую структуру и следит за длиной, тоном и типичными ошибками.

## Что нужно для использования

- Claude Code (или другой инструмент на базе Claude с поддержкой скилов).
- Аккаунт на GitHub нужен только для скачивания — не для самого
  использования.

## Как установить

1. На странице репозитория нажми зелёную кнопку **Code**, затем **Download
   ZIP**. Файл скачается в папку «Загрузки» (обычно называется
   `carousel-generator-main.zip`).
2. Найди этот файл в «Загрузках», нажми на него правой кнопкой мыши →
   **Извлечь всё...** → **Извлечь**. Рядом появится папка (обычно
   `carousel-generator-main`).
3. Открой Проводник (клавиши **Win + E** на клавиатуре).
4. Кликни в самую верхнюю строку окна Проводника (адресную строку, где
   обычно написано «Этот компьютер» или путь), сотри что там есть и вставь
   ровно это:
   ```
   %USERPROFILE%\.claude\skills
   ```
   и нажми **Enter**. Проводник сам откроет нужную папку на твоём
   компьютере — не нужно знать имя пользователя или искать её вручную.
   Если такой папки ещё нет — создай её: правой кнопкой мыши в пустом месте
   окна → **Создать** → **Папка**, назови `.claude`, зайди в неё двойным
   кликом, и так же создай внутри папку `skills`.
5. Перетащи папку из шага 2 (`carousel-generator-main`) в это окно
   Проводника. Если её название не `carousel-generator` — переименуй:
   клик правой кнопкой по папке → **Переименовать** → впиши
   `carousel-generator`.

   В итоге должен получиться путь:
   `...\.claude\skills\carousel-generator\SKILL.md`
6. Если Claude Code был открыт — перезапусти его.

## Как запустить

Просто напиши в чате, например:

> Сделай карусель про 5 ошибок при выборе фитнес-тренера

Claude сам найдёт и подключит эту инструкцию. Если не сработало само — можно
попросить явно: «используй скил carousel-generator».

Если ты не укажешь что-то из нужного, Claude переспросит:
- **тема** — о чём пост
- **ниша** — какая сфера
- **аудитория** — кто читает
- **желаемое действие** — что должен сделать читатель (сохранить,
  подписаться, написать слово в комментарии и т.п.)

## Пример входа и выхода

**Вход:** тема «5 нейросетей для маркетинга», ниша «маркетинг», аудитория
«бизнесмены», действие «сохранить».

**Выход (сокращённо, полностью — в `examples.md`):**

```
Слайд 1: «5 нейросетей, которые сделают часть работы маркетинга за вас» ·
«Пока конкуренты платят агентствам — держи бесплатный набор» · цифра 5 и
логотипы нейросетей

Слайд 2: «01 · ChatGPT — тексты и сценарии» · «Пишет посты, письма,
сценарии для рилс за минуты вместо часов» · логотип ChatGPT

...
```

## Чего генератор не делает

Не рисует и не собирает сами слайды — только текст и краткое описание того,
что должно быть на картинке. Дизайн, фото и финальную вёрстку каждый раз
делает человек.

## Файлы

- `SKILL.md` — основная инструкция для Claude.
- `structures.md` — три структуры карусели и общие правила (длина, тон,
  чего избегать).
- `examples.md` — готовые примеры по каждой структуре.
