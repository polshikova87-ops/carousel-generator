# Carousel Generator

## Overview

Turns a topic + niche + audience + desired reader action into a text
storyboard for a social media carousel (multi-slide post), slide by slide.
Picks one of three proven structures automatically based on the topic, and
applies fixed rules for slide count, text length, tone, and things to avoid.

## When to Use

- «Сделай карусель про...»
- «Нужна серия слайдов для поста про...»
- Any request for a carousel / carousel post for Instagram or a similar
  platform, on any topic or niche

Not for: designing the actual slides (fonts, photos, colors, layout) — that
part is always done by hand afterward. This skill only produces the text
storyboard.

## Process

1. Ask for whatever is missing, one question at a time:
   - тема (topic)
   - ниша (niche)
   - аудитория (audience)
   - желаемое действие читателя (сохранить / подписаться / написать слово в
     комментарии / и т.п.)
   If the user says "придумай сам" — propose a few topic options and let
   them pick, don't invent facts about their specific business or audience.
2. Pick the structure based on the topic (see structures.md for full detail):
   - Тема — сравнение чего-либо (плохо/хорошо, было/стало, миф/факт,
     слабое/сильное) → **Сравнение**
   - Тема — список шагов/инструментов/лайфхаков, которые естественно
     перечисляются → **Список-инструкция**
   - Всё остальное (истории, мнения, разборы, «почему так вышло») →
     **Крючок и разворот** (формат по умолчанию)
3. Apply the chosen structure and the universal rules below.
4. Output a text storyboard, one line per slide:
   `Слайд N: заголовок · текст · что на картинке`
5. Ask if any slide needs a revision. If the user corrects something, fix
   both the storyboard AND, if the mistake is general (not one-off), the
   relevant rule in structures.md — otherwise the same mistake comes back
   next time.

## Universal Rules (quick reference)

| Rule | Value |
|---|---|
| Slides | 6–10 |
| Text per slide | max 1–2 short sentences, no walls of text |
| Tone | expert, confident, bold, informative, viral |
| Avoid | canned/corporate language, empty clickbait, unverifiable promises, filler unrelated to the topic, numbers/calculations that require mental math |
| Tools/products named in a list | always name the specific product, never just the category |

Full structure descriptions: [structures.md](structures.md)
Worked examples of all three formats: [examples.md](examples.md)

## Common Mistakes

- Listing a tool category instead of the real product name (e.g. «приложение
  для видео» instead of «HeyGen»).
- Using numbers/calculations the reader has to do mental math for — replace
  with a vivid, instantly-graspable comparison instead.
- More than 1–2 sentences of text on one slide.
